## ✏️ Drawings

Each drawing is two files with the same name:

| file              | what it is                                                          |
| ----------------- | ------------------------------------------------------------------- |
| `name.excalidraw` | the source: open it in [Excalidraw](https://excalidraw.com) to edit |
| `name.svg`        | the picture the docs show: export it again after an edit            |

## 🔢 The numbers

- **D12** is a decision: see [decisions.md](decisions.md).
- **T12** is a task: each one has a GitHub issue with that title.
- **#12** is a pull request or an issue on GitHub.
