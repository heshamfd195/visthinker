# 📖 User stories

What Visual Thinker should let you do, and how we know it does. This file is living: it changes as the app does.

- ✍️ **To use it:** pick a story, build or test against its "Done when" lines, and mark ✅ only when every line is true in the app today.
- 🔄 **To update it:** change the status when the code changes, add new stories at the end of their group with the next free ID, and never reuse an ID.

| status | means       |
| ------ | ----------- |
| ✅     | works today |
| 🚧     | in progress |
| 🔜     | next        |
| 💭     | later       |

## ✏️ Drawing and editing

| ID   | story                                                                                                                             | done when:                                                                                                                                                                     | status |
| ---- | --------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------ |
| US01 | As a person thinking on paper, I want to draw freely with a pen, so that it feels like ink.                                       | ☐ The pen (P) draws smooth, pressure-aware ink.<br>☐ I can pick the pen colour, size and smoothing.<br>☐ The ink stays readable when I switch the canvas colour.               | ✅     |
| US02 | As someone sketching a diagram, I want to place boxes, circles, arrows and text from the toolbar, so that clean shapes are quick. | ☐ B, O, A and T pick box, circle, arrow and text.<br>☐ A dashed preview shows while I drag.                                                                                    | ✅     |
| US03 | As someone editing, I want to select by clicking, by a box or by a lasso, so that I can pick exactly what I mean.                 | ☐ The select button offers arrow, box and lasso.<br>☐ Shift adds to the selection.<br>☐ The box or lasso outline is dashed and marching while I drag.                          | ✅     |
| US04 | As someone editing, I want to delete what I picked, so that mistakes go fast.                                                     | ☐ The trash button and Delete / Backspace remove the selection.<br>☐ The eraser (E) removes what it touches.<br>☐ One undo brings it back.                                     | ✅     |
| US05 | As someone editing, I want handles on my selection, so that I can resize, rotate and move it.                                     | ☐ Corners and sides resize; Shift keeps the proportions.<br>☐ The handle above rotates and snaps every 45°.<br>☐ One undo restores the exact shape.                            | ✅     |
| US06 | As someone trying ideas, I want undo, redo and clear, so that nothing I try is final.                                             | ☐ ⌘Z and ⇧⌘Z undo and redo my own actions, never Claude's.<br>☐ Clear asks first, and one undo brings everything back.                                                         | ✅     |
| US07 | As someone who likes paper, I want dots, a grid or writing lines behind my drawing, so that I can keep things neat.               | ☐ Guides offer none, dots, grid or lines, with size, three opacities and dotted.<br>☐ Placed shapes can snap to dots or grid crossings.<br>☐ Guides are never read as strokes. | ✅     |
| US08 | As someone with a big drawing, I want to pan and zoom, so that I can move around it.                                              | ☐ The hand (H) pans the canvas.<br>☐ ⌘ or Ctrl + scroll zooms.                                                                                                                 | ✅     |
| US09 | As someone drawing for Claude, I want to see what the canvas read from my ink, so that I know what Claude will hear.              | ☐ Lines, boxes, circles and arrows I draw get a light blue outline; a crossing gets a blue dot.<br>☐ An X or O I draw gets a label with its score, e.g. `X 87%`, or `?`.       | ✅     |
| US10 | As someone reusing things, I want a library of shapes and symbols, so that I can drop them on the canvas.                         | ☐ I can drag artifacts and symbols from the library onto the canvas.<br>☐ I can add my selection to "Yours" and import symbols.                                                | ✅     |

## 🤝 Talking with Claude

| ID   | story                                                                                                                      | done when:                                                                                                                                                                                                                    | status |
| ---- | -------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| US20 | As a Claude Code user, I want Claude to open the canvas for me, so that I don't set anything up by hand.                   | ☐ Claude calls `open_canvas` and my browser opens the canvas.<br>☐ A second call doesn't open a second tab.                                                                                                                   | ✅     |
| US21 | As a Claude Code user, I want to add Visual Thinker with one line, so that trying it takes a minute.                       | ☐ `claude mcp add visthinker -- npx visthinker` works from npm. Today you build it from the repo first.                                                                                                                       | 🔜     |
| US22 | As someone drawing, I want Claude to get each stroke as events, so that it understands my drawing without a screenshot.    | ☐ Each stroke and each thing read from it arrive through `wait_for_event` or `get_events`.<br>☐ Claude can ask for the scene or a stroke's raw points.                                                                        | ✅     |
| US23 | As someone talking to Claude, I want a chat on the canvas, so that the talk stays next to the drawing.                     | ☐ What I type reaches Claude as a `message` event.<br>☐ Claude's replies and questions show in the chat, questions with answer buttons.<br>☐ A reply about one object puts a dot on it that opens the message.                | ✅     |
| US24 | As someone explaining, I want what I select to go with my message, so that "what is this?" means exactly that.             | ☐ The selection travels with the message as chips.<br>☐ Hovering a chip points at the object on the canvas.                                                                                                                   | ✅     |
| US25 | As someone waiting on Claude, I want to see Claude's status, so that I know if it's listening.                             | ☐ The chat and the events box say "Claude is listening", "Claude is connected, not watching" or "Not connected to Claude".<br>☐ While Claude works, the events box shows how long it has been thinking and each call it made. | ✅     |
| US26 | As the owner of my drawing, I want Claude to ask before changing what I drew, so that my work stays mine.                  | ☐ Claude adds, labels, moves and removes things by id with `act`.<br>☐ Moving or removing my own drawing is a proposal I apply or dismiss in the chat.                                                                        | ✅     |
| US27 | As someone learning or playing, I want Claude to act to fit the moment, so that it explains, asks or plays as I need.      | ☐ The modes button offers auto, playing, learning, teaching and contributing.<br>☐ In auto, Claude switches with a reason I can see.<br>☐ A mode I pick by hand holds until I choose auto.                                    | ✅     |
| US28 | As someone drawing, I want Claude to keep watching the canvas on its own, so that it reacts to drawing as much as to chat. | ☐ When Claude Code connects, the bridge tells Claude to stay in a listening loop on every event.                                                                                                                              | 🔜     |
