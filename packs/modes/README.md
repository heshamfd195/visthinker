# modes

The four modes of the canvas and the instruction card Claude follows in each (D129 · D138).

| mode         | Claude acts as                             |
| ------------ | ------------------------------------------ |
| playing      | your opponent: quick moves, short messages |
| learning     | a teacher who explains as you go           |
| teaching     | a student who asks while you show          |
| contributing | a co-author making a pack with you         |

Modes don't split the app: they describe the moment. In auto, Claude picks the mode from what you say and draw, through the `set_mode` tool, with a reason you see. Pick one by hand and Claude keeps to it until you choose auto again.

This pack is knowledge, not code (D139): copy it and edit `rules.json` to change how Claude behaves in a mode.
